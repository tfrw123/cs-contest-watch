# Contest logo sources

| Asset | Original source and preparation |
| --- | --- |
| `usaco.png` | [Official USACO site banner](https://usaco.org/current/images/usaco_logo.png). Removed the edge-connected white background and trimmed transparent margin. Both the full wordmark and tree are present. |
| `acsl.png` | [Original PNG linked by ACSL's home page](https://www.acsl.org/). Removed the edge-connected white background and trimmed transparent margin. Both lines of lettering are present. |
| `bcc.png` | Native beaver image and its transparency mask embedded on page 1 of the [official CEMC 2021 BCC contest booklet](https://cemc.uwaterloo.ca/sites/default/files/documents/2021/2021BCCContest9_10.pdf). This is the standalone mascot, without the surrounding cover layout. |
| `ccc.png` | Higher-resolution CCC lockup provided by the site maintainer. Trimmed only transparent outer padding. |
| `aio.svg` | [Official Australian Maths Trust SVG](https://amt.edu.au/wp-content/uploads/2021/01/AIO.svg). Added intrinsic dimensions matching the existing viewBox for PNG export. The circular badge is part of the source artwork. |
| `nzic.png` | Native NZOI image and its transparency mask embedded on page 1 of the [official NZIC Round Two solutions](https://www.nzoi.org.nz/nzic/past/2024/NZIC_2024_R2_Solutions.pdf). Trimmed only transparent pixels. This preserves the original letterforms without depending on a locally installed font. |
